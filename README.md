# Toy Story: imagnination in your hand 🌈👋
상상을 내 손 안에, 토이스토리

## Overview

- Toystory is a flutter application which helps children to make their own 3d model contents or toy using their imagination.
- 토이스토리는 아이들의 상상력을 현실로 만들어 주는 프로젝트입니다. 아이들이 상상하는 것들을 그림으로 그리거나 말로 표현하면 3D 모델링을 통하여 콘텐츠를 만들어 주고 3D프린터로 장난감을 프린트할 수 있습니다.
